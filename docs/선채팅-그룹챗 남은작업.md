## 완료 (요약)

- **N0 안 읽음/알림** — 세션별 안 읽은 응답 + 뱃지·미리보기, 알림 5겹(Notice/알림음/진동/OS/웹훅).
- **P1 선채팅**(챗 세션 전용) — 생성 코어(`ProactiveService`) + 스케줄러(빈도 범위 지터, 1분 틱, 시작 캐치업) + 누적 상한 + `{{idle_duration}}` + 복귀 독촉(7일/30일).
- **G1 슬라이스 1-2** — 그룹 엔티티(`StellaGroup`, GROUPS 폴더, store CRUD) + 세션 초대(사이드바 시나리오 우클릭, 그룹 자동 생성) + 멤버 디스크립션 주입(가상 로어북, 전원 상시 constant/before_char).
- **G2 챗 그룹 발화자 시스템 + G3 다듬기 + 그룹 선채팅** — 아래 체크 항목 참조 (2026-07-13, 배선 상세는 `구현현황.md` "그룹"). 트랙 사실상 완료 — 남은 건 그룹 전용 목록/탭 필요 여부(실물 보며 결정)뿐.
