# 시리즈/그룹/메뉴 회귀 방지 규칙

> 이 영역을 수정할 때만 읽는다. 규칙은 실제 사고에서 얻은 불변식이며, 구현이 바뀌면 현재의 올바른 경로만 남도록 갱신한다.

- **화 번호 = 만드는 화 + 1.** — max+1 로 건너뛰지 않는다(3화는 2화에서 만들어야 3화). 이미 같은 번호가 있으면 **다른 루트**가 된다(`resolveSeriesPlan` alternates → 모달 경고 + `(루트 N)` 접미사 + `prevId` 계보). **세션 복제는 시리즈 연결을 끊는다**(`copySession` 이 `meta.series` 삭제 — 같은 id+index 중복으로 화 목록이 꼬이는 것 방지).

- **그룹 세션은 GROUPS/ 밑에 별도 세션 트리를 만들지 않는다.** — 세션 파일은 호스트 시나리오 폴더(SCENARIOS/<host>/SESSIONS/)에 그대로 살고 `meta.groupId` 로만 링크. 세션 배관 전체가 SCENARIOS 경로를 가정하므로 병렬 트리는 대형 리팩터. group.json 은 멤버/설정 메타만 보유.

- **새 그룹 세션의 `groupId`·페르소나는 첫 세션 쓰기에 함께 넣는다.** — 일반 세션을 먼저 만든 뒤 `meta.groupId` 를 두 번째 저장으로 붙이면 중간 실패 때 그룹챗이 아닌 세션만 남는다. 그룹 파일 뒤 세션 생성이 실패하면 만든 그룹도 롤백한다.

- **그룹 초대 UI 를 세션뷰에 추가하지 않는다.** — 진입은 대시보드 홈 [그룹 만들기] + 좌측 사이드바 시나리오 우클릭 "현재 세션에 초대"뿐 (2026-07-11 결정, 시나리오 탭 진입 폐기).

- **세션 우클릭/롱프레스/⋮ 메뉴는 `session-menu.ts` `buildSessionMenu` 한 곳에서만 구성한다.** — 화면마다 메뉴가 달라 기능이 숨는 문제 방지. 새 세션 액션은 여기에만 추가. ⋮ 버튼은 상시 노출(우클릭/롱프레스는 사실상 숨김). 세션은 "이름"이 아니라 **"제목"** 용어(폴더형 엔티티만 "이름 변경").
