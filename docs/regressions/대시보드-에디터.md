# 대시보드/에디터 회귀 방지 규칙

> 이 영역을 수정할 때만 읽는다. 규칙은 실제 사고에서 얻은 불변식이며, 구현이 바뀌면 현재의 올바른 경로만 남도록 갱신한다.

- **대시보드 프롬프트 편집기는 우측 디테일 `PromptsSection` 을 재사용하지 않는다.** — PromptsSection 은 "현재 세션의 활성 세트" 화면이라 대시보드에서 쓰면 세트를 만질 때 세션 설정까지 바뀐다. → 전용 `PromptSetEditorSection`(세트 파일만 읽고 쓰며 활성 설정·세션 불변). CSS 클래스는 공유하되 코드는 분리.

- **편집기 진입은 단일 경로 `plugin.openStellaEditor(kind, file)`.** — 구 standalone 에디터 뷰 3종 + `openStellaView`/`mountStellaNav` 는 제거됨. 다시 만들지 않는다.

- **NSFW 안전 표시는 대시보드의 모든 이미지 선택 경로에 함께 적용한다.** — 홈 최근 삽화만 거르면 이어하기 카드의 세션 대표 삽화와 갤러리에서 그대로 노출된다. 판정은 `dashboard-content-safety.ts`, 대표 이미지 선택은 `latestMatchingIllustrationVariant`를 사용하며, 안전 variant가 없으면 이미지 없는 폴백으로 내려간다. 조건은 OR이고 모두 해제하면 기존 표시를 보존한다.
